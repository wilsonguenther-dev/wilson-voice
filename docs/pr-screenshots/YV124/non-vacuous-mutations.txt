corpus, and the arm returns before the declaration is ever read — so CI was
green with no declaration, the ci.yml comment named the wrong precondition
(models, not the corpus), and the expiry reached exactly one machine in the
world. Reproduced verbatim on the parent commit 5e84fc5:

(`..._unmeasured_expires_when_the_sidecar_gains_a_backend`), deletes the dead

stale `export` cannot outlive the state it described. M11-M15 break each of
those, one at a time.
