# Yap — Product

Local Wispr Flow alternative with a meeting notetaker. Researched against open-source
dictation apps and implemented as a real desktop product, not a script soup.

## What Yap does at 0.9.2

Every line is something a user of the 0.9.2 build can do today. Built-but-unwired work is
listed separately below it, and nothing aspirational is listed as shipped.

**Dictation**
- Hold a key (default **fn⌃**; fn, or either, selectable) and speak; release and the text
  is pasted into the frontmost app. A dictate-toggle chord and the click-to-dictate pill
  work without holding. Esc cancels a take in flight.
- On-device speech recognition: Parakeet 0.6B by default, Nemotron 0.6B or Whisper tiny
  selectable, in-process on Metal. Long takes decode in windows, with progress.
- Cleanup levels (light / medium / high; default medium): fillers, self-corrections,
  formatting, paragraphing; app-aware formatting. Optional local-LLM polish (Qwen2.5,
  downloaded on request) under a hard deadline — a late answer is dropped, never awaited.
- Undo restores the raw transcript. Dictionary (manual + learned terms), snippets
  (spoken trigger → saved text), command mode (voice edits on the current selection).
- A floating Dictate pill over full-screen apps on every Space, with live state.

**Meeting notes (notetaker)**
- Record a call (your mic + the other side via a CoreAudio process tap, macOS 14.4+; two
  tracks, never pre-mixed) or an in-person meeting (mic only, any supported macOS).
- Timed transcription that yields to dictation and resumes after a kill or a sleep.
- A local summary generated by the polish model; Markdown export; full-text search.
- Read-only calendar access names and prepares meetings. Meeting audio is kept until its
  transcript exists, then retained on a schedule.

**History and insights**
- Every dictation and meeting in local SQLite with FTS5 search, copy / re-paste, export,
  clear history. Words, WPM, streak and activity charts.

**License**
- Paid and proprietary after v0.7.0: $29 one-time lifetime license, a 14-day full-feature
  trial, verified offline from an Ed25519 signature. The gate refuses only a NEW dictation
  — history, exports, settings and meetings already recorded keep working forever.

**Privacy — the two network calls the app makes (PRIV-A)**
1. **Model download** — ASR, polish, VAD and diarization models, fetched once from
   Hugging Face (with the catalog mirror) or the pinned Silero commit on GitHub, each
   sha256-verified before it is used.
2. **Updater check** — the two `plugins.updater.endpoints`; on by default (`check_updates`),
   it notifies, and installs only when the user agrees.

The licensing path makes **no** network call since yap-lic-00. Audio, transcripts and
summaries never leave the Mac. There is no telemetry and no remote crash reporting;
crash reports and support bundles stay on the Mac unless the user chooses to share them.

**Built, not yet reachable by a user**
- Speaker diarization: the `yap-diarize` sidecar is bundled and its handshake is tested,
  but no meeting is handed to it yet (Y11).

## Why SQLite, not GraphQL

GraphQL is a **network API** for multi-client backends. Yap is a **single-user local app**. The correct local stack is:

- **SQLite (WAL + FTS5)** for durable storage + millisecond search
- **Typed Tauri commands** as the app “API” (no HTTP hop)
- Optional future: local HTTP/GraphQL only if a second process (mobile companion, web dashboard) needs the same data

FTS5 gives fast substring/prefix search over all past dictations — same retrieval UX as Wispr’s searchable Home feed.

## Data model

```
~/Library/Application Support/WilsonVoice/wilson_voice.db

transcripts          — every dictation (text, backend, asr_seconds, word_count, created_at)
transcripts_fts      — FTS5 virtual table (auto-synced via triggers)
dictionary           — personal terms + preferred spellings + hit counts
scratchpad           — freeform notes
daily_stats          — words/sessions/asr_ms per day (insights)
settings.json        — model, language, auto_paste, show_floating
```

## Pipeline

```
fn⌃ hold (CGEvent tap) → in-process cpal mic capture → 16 kHz mono
→ signal hygiene (high-pass, normalize, denoise) + Silero VAD
→ transcribe-cpp GGUF decode (warm engine, windowed for long takes)
→ cleanup level + dictionary rewrite (+ optional yap-polish LLM pass, hard deadline)
→ SQLite insert + FTS index
→ clipboard write → synthesized ⌘V on the main thread into the frontmost app
→ UI event + pill state
```

## Identity / TCC

Bundle id: `com.wilsonguenther.wilson-voice` — kept from the Wilson Voice era on purpose:
TCC grants are keyed to it, so renaming it would reset Microphone / Accessibility /
Input Monitoring for every install. The data directory `WilsonVoice` is frozen for the
same reason (it holds the SQLite history). See README.md.
Appears as **Yap** in Microphone / Accessibility / Input Monitoring.

## Run

```bash
cd desktop
npm run desktop:dev     # dev
npm run desktop:build   # sidecars + release .app + dmg
open "src-tauri/target/release/bundle/macos/Yap.app"
```

No interpreter or virtual environment is required; models are downloaded by the app.
