YV124 — non-vacuous mutations
=============================

Every assertion this item adds, deliberately broken one at a time, with the
failure it produces. Run from `desktop/src-tauri`. The tree is restored after
each run — this file is the record, not a committed mutation.

Why four and not one: this arm has three separable claims (the two decimators
differ on this audio; the pair labels come from the fixture; the scoring can
see the corruption OS-8 predicts) and a precondition (the fixture carries more
than one speaker). A mutation that only broke one of them would leave the
other three unproven.

Note on M1's -1.1 dB: with the shipped column swapped to the pre-fix
decimator, its folded energy is still measured against the Butterworth clean
control, so the ratio lands slightly below 0 dB rather than exactly at it. The
point stands either way — 28.3 dB of separation becomes none.
