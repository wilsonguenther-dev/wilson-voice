YV128 — every acceptance test, run against a deliberately broken build.

A test that cannot fail is documentation with a green tick. Each mutation below
was applied to the shipped source, the named test binary was run, the failure
recorded, and the source restored (`grep -c MUTATION src/*.rs` = 0 on the commit
that ships).
