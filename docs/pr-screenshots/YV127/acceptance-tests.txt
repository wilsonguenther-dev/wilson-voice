=== G1. the primary source the claim was checked against (not inferred from the API)
$ curl -sL https://raw.githubusercontent.com/k2-fsa/sherpa-onnx/v1.13.4/sherpa-onnx/csrc/offline-speaker-diarization-pyannote-impl.h
778 lines. The four call sites that settle it:

  L133  GetChunkSpeakerSampleIndexes(labels)  →  L373 ExcludeOverlap(labels)
        L446-467: zeroes every frame whose row-sum is >= 2, i.e. drops
        multi-speaker frames BEFORE embedding.  → the marker string is TRUE.

  L185  ReLabel(labels, …)  — the ORIGINAL labels, NOT ExcludeOverlap's output.
        ExcludeOverlap guards embedding only; it never touches the labels the
        result is built from.

  L190  FinalizeLabels(speaker_count, speakers_per_frame)
        L638-661: for each frame, keeps the top-k clusters where k is
        speakers_per_frame[i] — the segmentation model's OWN speaker count for
        that frame (L126, computed on the original labels). k >= 2 is exactly
        the overlap decision, and it survives into final_labels.

  L192  ComputeResult(final_labels)
        L663-725: walks each speaker_index's timeline INDEPENDENTLY, with no
        cross-speaker exclusion. Two clusters active in one frame therefore
        come back as two turns whose times INTERSECT.

  Conclusion: overlap is not unknowable — it is an interval intersection over
  turns DiarizeSegment {start, end, cluster} already carries. v1 still ships no
  column, because a derived flag needs its own tuning and its own acceptance
  evidence and nothing in yap23 asks for one. Reason restated as scope, in all
  four places the reviewer named.
