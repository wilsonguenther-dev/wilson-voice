# Yap Changelog

- YV1: Ported the polished pill into the live YappyPill — pull-back world-fill camera (drawImage source-rect), sky-blue capsule, word-count tier props (notepad+pencil / desk+typewriter+glasses), and tone-aware working chatter (rude/friendly/rose) driven by real app events.
- YV2: Renamed user-facing "Wilson Voice" → "Yap" (productName, window title, Info.plist display name + permission prompts, tray menu/tooltip, notifications, and all UI copy in desktop/src) while KEEPING the bundle id com.wilsonguenther.wilson-voice and the WilsonVoice data dir so macOS TCC grants and SQLite history persist.
- YV4: Ported the live-reaction pill into the live YappyPill — LIVE escalation WHILE listening (quick→notes→desk→essay by elapsed talk time, showing the matching prop + a tone-aware live line as you go, not just at done), a bigger open capsule (capW 236 / capH 60) with the camera zoomed to ~80% of the buffer so the chick + grass read larger, and slow drifting clouds; keeps the pull-back camera, sky-blue capsule, tier props, and tone-aware done line, all driven by the real recording/audio_level/transcript events.
- YV3: Smart dictation v1 (Wispr parity groundwork) — new pure Rust module `dictation.rs` with `mode_for_app` (frontmost app/bundle → Email/Document/Notes/Code/Chat/Plain) and `format_dictation` (enumerator-cue list detection → numbered list, else prose preserved), 7 unit tests, wired log-only at the transcribe site (source_app → mode) without touching the "never lose text" paste path.
- YV5: Wired smart dictation into the transcribe pipeline — `dictation::resolve_mode` (user-picked fixed mode wins, else `mode_for_app`) + `should_format` gate, then `format_dictation` runs on the transcript BEFORE it is stored/pasted, guarded so a non-empty transcript can never yield empty output (falls back to raw). Added a `dictation_mode` setting (Rust serde default "auto" + TS `dictationMode`) with a pill-style Settings picker (auto|plain|list|email|code|notes) and Rust `#[test]`s proving a fixed mode overrides the detected one and that `format_dictation` is applied.
- YV6: Backtrack v1 (Wispr parity groundwork) — new PURE Rust `clean_backtrack` in `dictation.rs`, called inside `format_dictation` behind the never-lose-text guard: drops standalone fillers ("um/uh/er/erm/hmm") + comma-bounded discourse hedges (", like," / ", you know," / ", i mean,"), and applies unambiguous spoken self-corrections — numeric "actually" restatement ("coffee at 2 actually 3" → "coffee at 3") and clause-retraction markers ("scratch that", "no wait") — while NEVER emptying non-empty input (all-filler utterances return unchanged). Rule-based groundwork for the later local-LLM pass; 5 new `#[test]`s cover filler removal, "actually" restatement, and content preservation.
- YV7: Error logging + diagnostics (support visibility) — new `logging.rs` tees every `env_logger` record to stderr (unchanged console) AND a hand-rolled size-rotating file at `data_dir()/logs/yap.log` (~2 MB, 4 backups), plus a `std::panic::set_hook` that records panic message + location + backtrace to the log. Added a `open_logs_dir` Tauri command (reuses the `open_data_dir` reveal pattern) surfaced as an "Export diagnostics (logs)" button in Settings; a `#[test]` proves rotation caps backups.
