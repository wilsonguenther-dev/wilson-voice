YV106 — the new tests fail when the behaviour they claim is removed.

Five mutations, each applied alone to the branch, run, then reverted. Every one
is a plausible "simpler" version of this item, not a syntax break.


MUTATION 1 — the index sidecar goes back to being shared (every track's records
into track 0's sequence), which is what "the journal needed no change" would
have shipped:

    pub fn index_track(&self, _track: usize, record: IndexRecord) {
        let Some(pending) = self.pending_index.first() else { return };
        pending.lock().push(record);
    }

    $ cargo test --test two_track_journal_round_trip
    test a_mic_only_meeting_is_byte_for_byte_what_22a_produced ... ok
    test two_tracks_round_trip_through_the_consumer_into_two_playable_wavs ... ok
    test a_loss_on_one_track_splices_that_track_only ... FAILED
    test a_journal_queue_drop_on_one_track_is_spliced_into_that_track ... FAILED
    test a_crash_mid_two_track_meeting_recovers_both_tracks ... ok
    test result: FAILED. 3 passed; 2 failed

  Both failures are the mic track coming back a second LONGER than it recorded,
  with the tap's hole spliced into it — the exact corruption per-track index
  sequences exist to prevent.
